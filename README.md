# Hard Locals — Content Operations

Система управления контентом для мотоклуба Hard Locals.

## Быстрый старт

1. Откройте `http://141.98.235.75:4000`
2. Логин: `admin` / пароль: из .env файла
3. Дашборд покажет: дни рождения, очередь, следующий маршрут

## Создание контента: два пути

### Путь 1: Ручной пост (1-2 мин)
1. **Sidebar** → выберите рубрику (Юмор, Мерч, Kind Reminder...)
2. Заполните поля (тема, повод) или оставьте пустыми
3. **⌘+Enter** или кнопка **✨ Сгенерировать**
4. Отредактируйте текст, используя тулбар **B I S** для форматирования
5. Прикрепите фото: **🔍 Найти фото** или **📎 Загрузить**
6. **⚡ Telegram** — отправить сейчас
7. **📅 Запланировать** — выберите дату/время, scheduler отправит автоматически

### Путь 2: Недельный план (5-10 мин)
1. **📅 Календарь** (шапка)
2. **📅 План на неделю** — создаёт 12-15 черновиков с правильным распределением
3. **✨ Сгенерировать всё** — AI заполняет текст каждого черновика
4. Пролистайте карточки, откройте нужные через **🖊 Полный редактор**
5. **🚀 Выпустить** — одобряет все с текстом, scheduler публикует по расписанию

## Scheduler (автопубликация)

- Проверяет очередь каждые **5 минут**
- Публикует посты со статусом **⏳ В очереди** когда наступает их время
- После публикации → статус **✅ Отправлен**
- Уведомление в личный TG после каждого поста

### Статусы
- ✏️ **Черновик** — нет текста или не одобрен
- ⏳ **В очереди** — текст есть, ждёт своего времени
- ✅ **Отправлен** — опубликован в канал
- ⚠️ **Ошибка** — не удалось отправить

## Автоматические процессы

| Процесс | Время | Что делает |
|---------|-------|-----------|
| Scheduler | каждые 5 мин | Публикует готовые посты |
| Утренний дайджест | 08:00 | План дня в личный TG |
| Авто-бэкап | ежедневно | Копия БД, хранит 7 дней |

## Медиа

- **🔍 Найти фото** — AI подбирает запрос, поиск по стокам
- **📎 Загрузить** — файл с компьютера (фото или видео)
- **🔗 С URL** — скачать видео из YouTube, Instagram, Rutube
- **🖼 Баннер** — текст поверх фото (для обложек)
- До 10 медиа в одном посте (карусель)

## Юмор: поиск мемов

1. В рубрике **Юмор** — ссылки на источники мемов
2. Откройте ссылку → найдите мем → правый клик → **Копировать адрес изображения**
3. Вставьте URL в поле → **📎 Прикрепить**
4. Напишите подпись → отправьте

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| ⌘+Enter | Сгенерировать пост |

## Управление пользователями (admin)

1. **Sidebar** → 🔧 Инструменты → **👥 Пользователи**
2. **+ Добавить** → логин, пароль, роль (admin/editor)
3. Editor может создавать и публиковать, но не управлять пользователями

## Техническое

- **Сервер:** Ubuntu 24.04, Docker
- **Стек:** Node 22, Express, SQLite, React CDN
- **Деплой:** `git push` → `docker compose restart`
- **Логи:** `docker compose logs --tail 50`
- **Бэкапы:** `/app/data/ops-backup-*.db`

## Поддержка

Проблемы → проверить логи → перезапустить:
```bash
docker compose restart
```

Полный сброс:
```bash
docker compose down && docker compose up -d
```
